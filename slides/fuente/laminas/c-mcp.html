Lo que lo distingue

El agente no tiene ni un esquema escrito a mano: list_tools() los descubre y call_tool() los ejecuta en el servidor.

Compáralo con

react.py: la misma herramienta, pero escrita dentro del agente; solo él podía usarla.

Ejecútalo

python -m ejemplos.s3_topologias.mcp_cliente
claude mcp add directorio -- python -m ejemplos.s3_topologias.mcp_directorio

Diez minutos. Primero ejecutar mcp_cliente.py: la primera línea dice qué herramientas descubrió, y en la pregunta sobre EMP-0099 el servidor responde con un error que regresa al modelo con is_error, igual que en react.py. Después, con el .venv activado, registrar el mismo servidor en Claude Code con claude mcp add, revisar claude mcp list, que debe decir Connected, abrir claude y preguntar quién es el empleado activo más antiguo de Tecnología: Claude Code pide permiso para usar la herramienta del servidor directorio. Señalar que el servidor no cambió: dos clientes distintos, cero líneas de integración. Al terminar, claude mcp remove directorio. El registro es local, no se guarda en el repo, para que los agentes de la fábrica no lo carguen.
