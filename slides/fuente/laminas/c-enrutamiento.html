Enrutamiento en código: una tabla de rutas

class Clasificacion(BaseModel):

    tipo: Literal["clara", "ambigua", "sospechosa"]

    motivo: str

 

def clasificar(s: Estado) -> Estado:

    c = modelo().with_structured_output(Clasificacion).invoke(

        "Clasifica esta historia: ..." + s["historia"])

    return {"tipo": c.tipo}

 

grafo.add_edge(START, "clasificar")

grafo.add_conditional_edges("clasificar", lambda s: s["tipo"], {

    "clara": "disenar_casos",

    "ambigua": "pedir_aclaracion",

    "sospechosa": "bloquear"})

Lo que lo distingue

Un clasificador con salida Literal y un diccionario valor → nodo. Solo se ejecuta una rama.

Compáralo con

Paralelización: allí se ejecutan todas las ramas a la vez.

Ejecútalo

python -m ejemplos.s2_flujos.enrutamiento

El programa clasifica tres historias: HU-01 (clara), una historia vaga (ambigua) y HU-99 (sospechosa). Señalar el Literal: con salida estructurada el modelo no puede inventar una rama. La tabla de rutas hace explícito el contrato. Adelanto de la sesión 4: la rama «bloquear» es una defensa; la historia envenenada nunca llega a un agente con herramientas.
