Antes de la sesión 1

Tu entorno, listo y verificado

Python 3.12 con uv

Node 20 o superior

Docker Desktop corriendo

Claude Code con sesión iniciada

Clave de API con créditos

Git y cuenta de GitHub

git clone <repo-del-curso> fabrica-empleados
cd fabrica-empleados
uv venv && source .venv/bin/activate
uv pip install -r requirements.txt
playwright install chromium
cp .env.example .env
# escribe ANTHROPIC_API_KEY y MODEL
docker info && claude doctor

Cada llamada a Claude Code tiene un tope de gasto: PRESUPUESTO_USD en .env (2 USD por defecto)

Envíen esta lista una semana antes. El archivo .python-version fija Python 3.12; con uv, el entorno se crea con esa versión aunque haya otra más nueva instalada. Docker Desktop y Playwright corren a la vez en la sesión 3, por eso conviene una máquina con al menos 8 GB de RAM. Pidan a los estudiantes revisar su consumo en la consola de Anthropic al final de cada sesión. Reserven los primeros minutos de la sesión 1 para los rezagados.
