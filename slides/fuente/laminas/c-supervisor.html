Supervisor en código: él decide con Command

class Decision(BaseModel):

    siguiente: Literal["analista", "tester", "desarrollador", "FIN"]

 

def supervisor(s: Estado) -> Command[Literal[...]]:

    if s["vueltas"] >= MAX_VUELTAS:

        return Command(goto=END)

    d = modelo().with_structured_output(Decision).invoke(...)

    return Command(goto=END if d.siguiente == "FIN" else d.siguiente,

                   update={"vueltas": s["vueltas"] + 1})

 

for nombre in AGENTES:

    grafo.add_node(nombre, especialista(nombre))

    grafo.add_edge(nombre, "supervisor") # su única salida

grafo.add_edge(START, "supervisor")

Lo que lo distingue

Command(goto=…) solo en el supervisor; cada especialista tiene una sola arista: de regreso a él.

Compáralo con

Red: allí todos los nodos devuelven Command.
