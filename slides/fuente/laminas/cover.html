Programa NextGen · Módulo 3

Construcción de Sistemas Agénticos

Qué es un agente, cómo validar lo que produce, cómo orquestarlo con personas en el flujo y qué arquitectura elegir. Todo aplicado en una fábrica de agentes con Python y Claude Code.

10 horas

4 sesiones

6 agentes

Trabajo individual

Bienvenida. En este módulo cada estudiante construye su propia fábrica de software: una cadena de seis agentes que toma una historia de usuario y entrega una aplicación de gestión de empleados de una empresa, con base de datos, API y front-end en React, desplegada con Docker y probada de punta a punta. Todo se programa en Python, y Claude Code es tanto el asistente como el motor de tres de los agentes.
