Orquestador en código: Send

class Subtareas(BaseModel):

    subtareas: list[str] # cuántas: lo decide el modelo

 

def orquestador(s: Estado) -> Estado:

    plan = modelo().with_structured_output(Subtareas).invoke(...)

    return {"subtareas": plan.subtareas}

 

def repartir(s: Estado) -> list[Send]:

    return [Send("trabajador", {"subtarea": t})

            for t in s["subtareas"]]

 

grafo.add_conditional_edges("orquestador", repartir, ["trabajador"])

grafo.add_edge("trabajador", "sintetizar") # espera a todos

Lo que lo distingue

Send crea un trabajador por subtarea en tiempo de ejecución; el grafo solo tiene un nodo «trabajador».

Compáralo con

Paralelización: dos ramas fijas, escritas en el grafo.
