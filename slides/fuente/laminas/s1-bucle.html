Sesión 1 · Arquitectura de agentes

Este es el corazón de cualquier agente, incluido Claude Code. El usuario da un objetivo; el modelo responde con texto o con una petición de herramienta (stop_reason = tool_use). Si pidió herramienta, el código la ejecuta y devuelve el resultado, o el error, como un nuevo mensaje. Se repite hasta que el modelo responde sin pedir herramientas o se alcanza el límite de pasos. Mostrar en vivo una sesión de Claude Code y señalar cada vuelta del bucle en su salida.
