Claude Code aparece en tres papeles. Como asistente, en la terminal, ayuda a entender y depurar el código de la fábrica. Como caso de estudio, es un agente real cuyo diseño analizamos. Y como motor: los agentes desarrollador, despliegue y automatizador no usan un bucle propio, sino que delegan en Claude Code mediante el Claude Agent SDK, con una carpeta, herramientas, permisos y presupuesto que definimos nosotros. La regla del módulo: nada dentro de app/ se edita a mano; si algo falla, se corrigen las instrucciones, las convenciones o el plan, y se vuelve a ejecutar.
