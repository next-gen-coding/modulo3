Sesión 3 · Conectar agentes con herramientas · A2A hace lo mismo entre agentes de distintos sistemas

MCP, Model Context Protocol, es un estándar abierto para conectar agentes con herramientas y datos. Sin él, cada agente escribe sus propios esquemas y conectores: con M agentes y N sistemas son M por N integraciones. Con MCP, cada sistema publica un servidor una vez y cualquier cliente lo usa. El servidor publica herramientas, recursos y prompts; en clase usamos solo herramientas. El cliente hace dos cosas: list_tools para descubrir qué hay, con su descripción y esquema, y call_tool para ejecutarla. Lo importante para el curso: MCP no cambia el bucle del agente, cambia de dónde salen las herramientas. A2A, Agent2Agent, es el estándar hermano para que un agente le delegue una tarea a otro agente de otro sistema; aquí solo lo mencionamos. Puente a la sesión 4: la descripción de la herramienta entra al contexto del modelo, así que un servidor MCP de terceros es código y texto que no escribimos. Es la cadena de suministro de ASI04: revisar, fijar versiones y publicar lo mínimo, de solo lectura.
