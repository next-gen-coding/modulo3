El flujo es un grafo con estado

Estado

Un TypedDict viaja por el grafo. Cada nodo devuelve solo lo que cambia.

Nodos y aristas

Funciones Python o LLM. Las aristas condicionales eligen el siguiente nodo.

Checkpointer

Guarda cada paso por thread_id: reanudar, pausar y depurar.

g = StateGraph(Estado)
g.add_node("verificar", verificar)
g.add_conditional_edges("verificar", despues_de_verificar)
app = g.compile(checkpointer=InMemorySaver())

25 minutos. El estado es la memoria del flujo; los reducers definen cómo se combinan las actualizaciones (sobrescribir o concatenar listas, como la bitácora y el costo de la fábrica). Las aristas condicionales son funciones que leen el estado y devuelven el nombre del siguiente nodo: aquí el código decide, no el modelo. El checkpointer guarda el estado tras cada paso, lo que permite reanudar tras una caída, pausar para aprobación humana y viajar en el tiempo para depurar. Los mismos conceptos existen en Microsoft Agent Framework y otros. En la fábrica, el estado guarda la historia, las rutas de los artefactos, el plan, los intentos y el costo acumulado.
