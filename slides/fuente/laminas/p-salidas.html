Sesión 1 · Salidas estructuradas y validación

Objetivo 2 del módulo. Un agente que entrega texto libre no se puede encadenar ni verificar. La salida se diseña como un contrato: un modelo Pydantic con tipos, campos obligatorios y valores permitidos, más un campo de dudas para que el modelo diga lo que no sabe en lugar de inventarlo. El modelo lo llena forzando una herramienta cuyo esquema es el contrato. Después, el código valida en tres niveles: el esquema, las reglas de negocio que el tipo no expresa, y pruebas ejecutables que confirman que el resultado funciona. Si algo falla, el problema regresa al modelo como contexto, con un tope de intentos. Si se agota el tope, decide una persona: ese es el puente con el objetivo 3.
